# Shepherdiland 需求規格（使用者原文）

網站名稱叫「我的回訪」（品牌名 Shepherdiland），用來管理我在校園福音工作中接觸的大學生名單（亞洲大學、朝陽科技大學）。以手機使用為優先設計，介面文字全部使用繁體中文。後端使用 Supabase（Auth、Postgres 資料庫、Storage、Edge Functions）。

【一、整體風格】
- 溫暖、明亮、療癒的可愛風格，配色柔和
- 3D 場景使用 Three.js，採用低面數（low-poly）畫風，保持可愛卡通感，不要改成寫實風格
- 圓角卡片、柔和陰影、友善的圖示

【二、主畫面版面（手機優先）】
上半部：3D 島嶼場景
- 兩座浮在海上的低面數小島：「待聯繫島」（本週還沒聯繫的人）、「本週已聯繫島」（本週已經聯繫過的人）
- 每位名單成員是一個 Q 版 3D 小人，在島上隨機走動，偶爾揮手或轉圈（情緒狀態會影響動作）
- 小人頭上浮著名牌，顯示名字、學校、科系、敞開程度
- 標記「本週已聯繫」時，小人播放跳躍動畫，跳過海面到另一座島
- 每週一 00:00 自動把所有人移回「待聯繫島」
- 右上角「本週進度圈」，例如「本週 3/5 人」，目標人數可自訂

下半部：可上拉的清單面板（bottom sheet）
- 「今天的約」：時間、對象、地點、經文，旁邊導航按鈕用 Google 地圖開啟
- 「快快聯繫」：依超過回訪目標程度排序；每列：頭像（小人目前表情）、名字、學校・科系、敞開程度色點、距上次聯繫天數
- 每列右側 LINE 與 IG 按鈕 deep link：
  - LINE 個人：https://line.me/ti/p/~{LINE ID}
  - LINE 官方：https://line.me/R/oaMessage/{LINE ID}/
  - IG：https://instagram.com/direct/t/{使用者名稱}，備援 https://ig.me/m/{使用者名稱}
  - 每位成員可設定 LINE 帳號類型（個人／官方）

第二畫面：清單上拉全螢幕
- 上方只露一小條島嶼；「本週回訪」標題與進度圈；今天的約（時間軸卡片）；完整「該聯繫了」名單（含 LINE、IG）
- 「敞開程度分布」：五色分段橫條
- 「心情分布」：開心、有點失落、沮喪、很久沒見各幾位

底部分頁列：島嶼、名單、行程、統計，中間凸起「＋」新增按鈕

【三、3D 場景多角度查看】
- OrbitControls：手機單指旋轉、雙指縮放、雙指平移；電腦左鍵旋轉、滾輪縮放、右鍵平移
- 水平 360 度；垂直限制在海平面以上；縮放最近/最遠距離限制
- 開啟 damping
- 視角不自動跟隨小人
- 名牌 billboard 永遠面向鏡頭
- 閒置一段時間 auto-rotate，一碰就停
- 「重設視角」按鈕
- 點小人時鏡頭平滑拉近再開詳情頁
- 3D 區域拖曳不觸發頁面捲動或 bottom sheet 上拉

【四、敞開程度】5 級：1 灰 冷淡、2 藍 禮貌、3 綠 有興趣、4 黃 想讀經、5 金色發光 固定讀經

【五、回訪頻率目標與小人情緒】
1. 目標：間隔模式（每 N 天至少一次，預設每 2 天）或次數模式（每週至少 N 次，週一到週日）。新增預設每 2 天，可在表單與詳情頁調整。設定頁可改全體預設與依敞開程度的預設。詳情頁顯示「目標：每 2 天一次，已經 3 天沒聯繫」或「本週 1/3 次」。
2. 情緒：😊 開心（目標內）；😐 有點失落（間隔超過 0–100%；次數模式本週進度落後）；😢 沮喪（間隔超過 1 倍以上；次數模式週末前已不可能達標）；💤 很久沒見（超過 5 倍或超過 30 天）。開站時計算、每小時更新。
3. 3D 呈現：
- 開心：活潑走、跳、揮手、轉圈、笑臉、眼睛閃亮
- 有點失落：走慢、停下東張西望、平淡嘴型、偶爾「…」泡泡
- 沮喪：拖步、低頭塌肩垂手前傾、眉下垂嘴角向下淚光、頭頂灰烏雲下小雨、周圍略暗、偶爾坐下抱膝嘆氣
- 很久沒見：多半坐在島邊、半透明、灰烏雲
- 狀態間平滑過渡；程式控制關節旋轉；臉部可替換貼圖或低面數五官
- 名牌旁情緒小圖示
4. 求關注（失落、沮喪、很久沒見）：
- 難過 4–6 秒與求關注 3–4 秒交替
- 動作隨機：原地蹦跳、高舉雙手揮、轉向鏡頭蹦跳靠近到島邊、指自己或打電話手勢、泡泡「我在這裡！」「來找我聊聊～」「好久不見😢」「想你了」
- 不論鏡頭角度都轉身面向鏡頭揮手
- 遞增：失落約每 15 秒輕跳輕揮；沮喪每 6–8 秒頻繁跳、揮雙手、跑向鏡頭，烏雲跟著晃；很久沒見從坐姿站起跳揮再失望坐回
- 求關注時名牌輕微放大＋柔和脈衝光圈
- 多人錯開時間
- 震動 API（同意後）：開站時若有沮喪小人輕震一下
- 設定頁可調頻率或關閉
- 點求關注中的小人，開心跳一下再進詳情頁
5. 恢復：新增互動紀錄後立即開心、停止求關注；動畫：烏雲散開、彩虹或愛心、跳起揮手，跳到已聯繫島。次數模式未達標時開心但名牌顯示「1/3」。
6. 提醒：沮喪者排在「快快聯繫」最前；瀏覽器通知（同意後）每天早上提醒今天的約與沮喪/很久沒見的人；點通知開詳情頁。

【六、個人詳情頁】
- 頂部 3D 小人站小島（當前情緒）、名字、學校、科系、年級、敞開程度標籤
- 回訪目標與狀態，可點擊修改
- 「💡 這次可以聊」建議卡片
- 約定事項（日期時間、地點、經文、倒數）
- 最近聊天時間軸（日期與 AI 摘要，點開看原始截圖）
- 代禱事項（可標記已蒙應允）
- 讀經進度（書卷、章，進度條）
- 生活近況；怎麼認識的、備註
- 底部「用 LINE 聊天」「用 IG 聊天」大按鈕
- 「＋ 新增互動紀錄」：日期、方式（見面／LINE／IG／電話）、摘要、下次約定；存檔更新最後聯繫日期、小人恢復開心並跳島
- 「📷 上傳聊天截圖」
- 可編輯、刪除成員

【七、聊天截圖上傳與 AI 分析】
1. 上傳：相簿或拍照、多張、可拖曳排序；打碼工具（手指塗抹）；上傳前壓縮長邊 1600px WebP
2. Storage：私有 bucket chat-screenshots；路徑 {user_id}/{contact_id}/{日期}_{序號}.webp；表 screenshots（id、contact_id、interaction_id、storage_path、上傳時間、排序）；signed URL 1 小時；永久保存直到手動刪除
3. AI：Edge Function analyze-chat 呼叫具視覺能力模型（OpenAI GPT-4o 或 Gemini），金鑰只在 Edge Function secrets。固定 JSON：summary、topics、appointment（日期、時間、地點、經文，相對日期換算）、prayer_requests、bible_progress、life_updates、openness_hint（含理由）、follow_ups、chat_date。分辨左右泡泡誰說的。分析時顯示可愛等待動畫（小人看手機）。
4. 確認：存檔前顯示結果可修改，按「存進紀錄」。存檔後新增互動紀錄（方式帶入 LINE/IG，連結截圖）、約定加入行程、代禱/讀經/近況更新、敞開程度只顯示建議需確認、更新最後聯繫日期、小人恢復開心跳島。

【八、💡 這次可以聊】
- 依過去紀錄、摘要、代禱、讀經、近況、待辦承諾產生：3 個可以聊的話題、要記得的事、關心一下、沮喪/很久沒見時一句不帶壓力的開場白、即將到來約定的準備提醒
- Edge Function suggest-topics 產生；快取於 suggestions（contact_id、內容、產生時間），有新互動才重產
- 「重新產生」按鈕、一鍵複製、👍／👎
- 語氣自然溫暖、不壓迫

【九、Supabase】
- Auth：Email magic link 或 Google
- 表：contacts（名字、學校、科系、年級、敞開程度、LINE ID、LINE 類型、IG、怎麼認識的、備註、小人外觀、最後聯繫日期、frequency_mode interval/weekly、frequency_value）、interactions（日期、方式、摘要、話題、AI JSON）、appointments（日期時間、地點、經文、狀態）、prayer_requests（內容、日期、是否應允）、screenshots、suggestions、settings（全體預設、依敞開程度預設、求關注頻率與開關、震動開關、通知設定）
- 情緒即時計算不存欄位
- 所有表 RLS：只能讀寫 user_id = 自己
- Storage RLS：只能存取自己 user_id 資料夾
- 提供 SQL、RLS、Edge Function 程式碼與部署步驟

【十、個資保護】
- 上傳前提醒可打碼；上傳畫面一行提醒：「截圖可能含有對方個資，請妥善保管，只供個人關懷使用」
- bucket 私有、RLS 開啟；service role key 與 AI 金鑰只在伺服器端
- 不把真實名單、截圖放公開倉庫
- 設定頁說明截圖會傳給哪個 AI 服務
- 「刪除這位成員的所有資料」一鍵刪除資料庫紀錄與所有截圖
- 「匯出我的資料」，匯出時提醒含個資

【十一、日夜循環】依當地時間平滑漸變：
- 早上 5–10：淡藍天空、晨霧、日出、鳥飛過、小人伸懶腰
- 白天 10–16：明亮、活潑
- 黃昏 16–19：橘粉天空、影子拉長、海面金光、燈籠亮起
- 晚上 19–5：深藍星空、月亮、螢火蟲、小人圍營火坐或打瞌睡、名牌微發光
- 日夜動作與情緒疊加（晚上沮喪者坐營火旁低頭，但求關注仍站起朝鏡頭揮手）
- 天空、光源角度、陰影隨時間；日月沿弧線移動
- UI 卡片淺色／深色主題跟著切換
- 角落按鈕手動切換時段預覽

【十二、其他】
- 名單分頁：搜尋、依學校、科系、敞開程度、情緒篩選
- 行程分頁：月曆
- 統計分頁：每週聯繫人數趨勢、目標達成率、敞開程度分布、各校人數
- 新增成員表單：名字、學校、科系、年級、敞開程度、回訪頻率、LINE ID 與類型、IG、怎麼認識的、備註、小人外觀（髮型、衣服顏色）
- PWA 可加入主畫面、離線瀏覽已載入資料
- 低階手機自動降畫質（保留求關注動作、減少粒子）

【十三、範例資料】6 位虛構名單（亞大、朝陽各半，敞開程度各不同，目標有每 2 天與一週至少 3 次），四種情緒至少各一位；每位 1–2 筆互動與一張建議卡；另加 2 筆今天的約定。全部虛構，不放真實個資。
